About Ebbfall

Ebbfall is a free real-time strategy game for the browser, made for fun by Stelian Matei.

Who and how

Made by Stelian Matei. Everything is generated by code: the 3D-rendered sprites, the painted terrain, the synthesized sounds and voices.

The game is a deterministic simulation in Rust, compiled to WebAssembly. Multiplayer runs the same simulation in lockstep on every player's device, through a small relay.
